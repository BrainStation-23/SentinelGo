- YARA: rules can use the `pe` module (#419). Rules with `import "pe"` used to be skipped as `unsupported_module:pe`. They now compile and match Windows executables on headers, sections, imports, exports, imphash, Rich header, resources, version info and Authenticode signature metadata. An executable up to 64 MiB is read whole so fields at the end of the file (signatures, checksum) work. Larger ones stream, and those fields stay undefined. `elf`, `macho` and `dotnet` are still unsupported.
