- YARA: a running scan reports its progress (#498). Scheduled and on-demand scans send a `scan_progress` event with the files scanned, skipped and failed so far, the matches, which folder of how many it is in and how long it has run, at most every 2 minutes. No paths are sent. Only the latest progress waits in the queue while the device is offline. The agent sends it only when the server's bundle asks for it, so older servers never receive it.
