- macOS: releases can ship code-signed agent binaries (#352). When the `MACOS_CODESIGN_P12` and `MACOS_CODESIGN_P12_PASSWORD` secrets hold a code-signing certificate (an internal CA's for now, later Developer ID), the release workflow signs `sentinelgo-darwin-amd64` and `sentinelgo-darwin-arm64` on a macOS runner with the identifier `com.sentinelgo.agent` and the hardened runtime, before the Ed25519 signatures, `SHA256SUMS` and SBOMs are made. Without the secret the binaries ship unsigned, as before. MDM profiles (Full Disk Access, notifications) can then pin the agent by a signature that stays the same across releases. `install.sh`, `sentinelgo -install` and the updater now keep a certificate signature that verifies, and sign ad-hoc only binaries that have none. Before this change they always re-signed ad-hoc, which replaced any certificate signature. See RELEASE.md, "macOS code signing".
