- YARA: scan summaries say why files weren't scanned and why a scan stopped (contract v1.2, #497; capability `yara_scan_report_v1`). They now carry skips and errors by reason (too large, timed out, access denied, locked, listing failed, …), the end reason (time or file limit, cancelled, threat hunting turned off, worker failure, shutdown), the bytes read, the time paused for the CPU budget or battery, the scope (folders, exclusions, limits, ruleset revisions) and up to 200 problem files with the OS error text. In hashed path mode their paths are hashed like match paths. A stopped scheduled scan keeps the breakdown when it resumes. All fields are optional, so older servers ignore them.
