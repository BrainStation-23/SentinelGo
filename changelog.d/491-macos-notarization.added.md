- macOS: releases notarize the agent binaries with Apple (#491). When the binaries are signed with a Developer ID certificate and the `APPLE_NOTARY_KEY_P8`, `APPLE_NOTARY_KEY_ID` and `APPLE_NOTARY_ISSUER_ID` secrets hold an App Store Connect API key, the release submits both binaries with `notarytool` after code signing. Developer ID signatures now carry Apple's secure timestamp, which notarization requires. If Apple rejects the binaries the release stops; if Apple doesn't answer within 30 minutes the release goes out signed, with a warning. Signatures from an internal CA are signed as before and not notarized.
