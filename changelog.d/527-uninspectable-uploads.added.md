- File DLP: the upload inspection status reports uploads to listed sites that the proxy couldn't inspect (#527). `files.deep_inspection.uninspectable_counts` counts them by reason (`tls_untrusted`: an app refused the inspection certificate, so it pins certificates or doesn't trust the device CA; `websocket`: a WebSocket connection, relayed but not read; `too_large`: over `max_file_bytes`). `uninspectable_hosts` lists up to 20 hosts with reason, count and first/last time, the host only. Admins can now tell "inspected and clean" from "never inspected". They aren't sent as DLP events yet, because the server doesn't accept them.
