- Updates: agents roll back to an older release when the console marks it as latest for an emergency rollback (#505). The server sets `allow_downgrade` on the `get_latest_agent_release` row only during an admin-initiated rollback. Without it an older release is still ignored, and equal versions never reinstall. The SHA-256 and signature checks still apply. Scheduled checks, the startup check and the `agent-update` task (push now) all follow this rule. The agent logs `Rolling back: vA -> vB (server-approved downgrade)`.
