- YARA: a Windows executable whose first bytes look like UTF-16 text is still typed `executable.pe` (#419), so `pe` rules see the whole file (signatures, checksum, resources) and the `filetype` external is right. This includes executables whose PE header starts past the first 8 KiB: the engine confirms those from the whole file (up to 64 MiB), whatever the ruleset imports. DLP evidence reports these files as `executable.pe` too, not `text.utf16le`.
