- macOS: releases include `sentinelgo-darwin-universal.pkg`, a generic installer package for MDM (#352). It holds one universal binary at `/opt/sentinelgo/sentinelgo` and no `config.json` (the agent enrolls from MDM managed preferences), and installs and starts the launchd job with `sentinelgo -install`. When the `MACOS_INSTALLER_P12` secret holds a Developer ID Installer certificate, the package is signed, notarized and stapled, and listed in `sentinelgo-installers.json` for the backend's MDM mirror. Until then it ships unsigned and isn't listed, since MDM can't install it. CI builds and test-installs the package on every pull request.
