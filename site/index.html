SentinelGo is a single, dependency-free binary that turns every Windows, macOS and Linux device into a continuously monitored, audit-ready endpoint: hardware inventory, security posture, encryption status and tamper-evident audit logs, streamed to your backend in real time.

Why teams choose SentinelGo

Most compliance and asset-management tools ship a heavy stack: a kernel module here, a Python runtime there, a different installer per OS. SentinelGo takes the opposite approach.

Zero dependencies

Every build is a CGO_ENABLED=0 static binary. No runtime, no shared libraries. Drop one file on a machine and it runs.

Stays current on its own

Built-in self-update downloads the right signed binary for the platform, verifies it and replaces itself atomically.

A first-class service

Native Windows Service, systemd unit and launchd daemon. Installs with one command, survives reboots and restarts on failure.

Built for compliance

Durable, at-least-once audit-log delivery backed by a local SQLite queue. Events survive outages and reboots instead of being dropped.

Tiny footprint

A single background process designed for minimal CPU and memory impact. Built to monitor, not to get in the way.

Secure by design

Per-agent JWT authentication, HTTPS-only transport, Row Level Security on every endpoint and PII redaction before data leaves the machine.

What it captures

A live, structured picture of every endpoint, far beyond "is it online".

Hardware & system

CPU, memory, per-disk capacity and health, GPUs, RAM modules, displays, audio devices, printers and peripherals. OS version, architecture, locale, uptime and last boot.

Security posture

  • Disk encryption: BitLocker, FileVault, LUKS
  • Antivirus and firewall state
  • Secure Boot, VBS/HVCI, SIP, SELinux/AppArmor
  • Listening ports by process; TPM and firmware

Network

Per-adapter MAC, link speed and status, IPv4/IPv6 addressing, DHCP, gateway, DNS servers, and Wi-Fi SSID with signal strength.

Software inventory

Installed applications from Windows, Microsoft Store, Debian/RPM/Snap/Flatpak, Homebrew and the Mac App Store, with change tracking. Plus browser extensions for Chrome, Firefox, Edge and Brave.

Audit log streaming

Normalized events from Windows Event Log, Linux auth/syslog and journald, and the macOS unified log. Categorized, severity-tagged, checkpointed and uploaded in batches.

Local accounts

Local user accounts with group membership, without collecting any credential material.

Runs everywhere your fleet does

Every target is cross-compiled from a single host into a static binary. No per-platform build farm required.

How it works

The agent authenticates, reports, streams and keeps itself up to date, with no hand-holding after install.

Authenticate

The agent logs in to a Supabase Edge Function and receives a short-lived JWT, refreshed automatically in the background.

Report

System metrics are sent as a heartbeat on a configurable interval (default 5 minutes), plus periodic full hardware and software inventory.

Stream

Audit logs are collected from OS-native sources, normalized, durably queued in SQLite and uploaded with at-least-once delivery.

Stay current

The agent polls for new releases, downloads and verifies the signed binary, replaces itself atomically and restarts cleanly.

Get started

Download a release for your platform from GitHub Releases, verify it, create a config.json and install the service.

Install as a service

# Verify the download against the published checksums
sha256sum -c SHA256SUMS --ignore-missing

# Linux / macOS (as root)
sudo ./sentinelgo -install

# Windows (as Administrator)
.\sentinelgo.exe -install

# Run in the foreground for debugging
./sentinelgo -run

Full per-OS walkthrough: INSTALLATION.md

Configure

The agent reads one JSON file at /opt/sentinelgo/.sentinelgo/config.json (Linux, macOS) or C:\sentinelgo\.sentinelgo\config.json (Windows).

{
  "supabase_url":         "https://<your-project>.supabase.co",
  "supabase_key":         "<anon-key>",
  "agent_secret":         "<agent-login-secret>",
  "auto_update":          true,
  "update_interval":      "5m",
  "audit_logs_enabled":   true
}

Full reference: configuration docs

Build from source

Requires Go 1.26 or newer. All builds are CGO_ENABLED=0 static binaries.

git clone https://github.com/BrainStation-23/SentinelGo.git
cd SentinelGo
make build     # dev build -> bin/sentinelgo
make test      # run the test suite

Security & privacy

An agent that runs with elevated privileges on every machine has to earn trust. Here is how SentinelGo does it.

In the agent

  • All backend traffic is HTTPS with a per-agent JWT obtained at runtime. No credentials are embedded in the binary.
  • Account inventory captures usernames and groups only, never credential material.
  • PII and credential-like patterns are redacted from task output before upload.
  • Updates are signed and verified before the binary is replaced.

In the project

  • Every release ships a SHA256SUMS file; installers refuse to run without it.
  • CI runs CodeQL, gosec, govulncheck, Trivy and SonarCloud on every change.
  • Parsers of untrusted input are fuzzed nightly.
  • Vulnerabilities are reported privately. See the security policy.
